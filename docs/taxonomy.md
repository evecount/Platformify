
# Behavioral Taxonomy: Universal Purchase Signals

This is the dictionary of "Hidden Variables" that the Platformify agents track across all niches.

| Signal Key | Description | Prediction Weight |
|------------|-------------|-------------------|
| `urgency` | How fast the user needs to book. | High (Impacts Price) |
| `intent` | Gift, Business, Celebration, or Utility. | Medium (Impacts Vibe) |
| `sensitivity` | How many lower-priced options were rejected. | High (Impacts Yield) |
| `aesthetic` | Preferred visual style (Minimal, Lush, Brutalist). | Low (Impacts Previews) |
| `overhead` | Ratio of operational cost to price. | Critical (Impacts Profit) |

## The Global Purchase Persona
Agents should aim to categorize every `Customer` into a cross-platform persona:
1. **The Premium Seeker:** High budget, low sensitivity, aesthetic-driven.
2. **The Utility Optimizer:** High sensitivity, logic-driven, urgent.
3. **The Relationship Builder:** High intent (Gift), emotional-driven.
